ski-ghostline

同じ場所から撮った2本の滑走を重ね、1本の動画にします。編集はコーチが行い、選手には完成した動画だけを渡します。

アプリを開く

このアプリでできること

  • メインの滑走を下地にし、もう1本を半透明のゴーストとして重ねます。
  • スタートゲートなど、同じ瞬間を両方で印すと、そこから先は実時間で再生されます。速い選手が前に出ます。
  • それぞれの動画に入っている音も入ります。音量は別々に変えられます。
  • 1080p の MP4 を書き出します。ログインは不要です。動画はこの端末の中だけで処理し、サーバーには送りません。

撮影するときの注意

重ね合わせは、2本が同じ画面になることが前提です。撮影でずれた分は、アプリでは位置と大きさだけ直せます。傾きは直せません。

カメラ

  • 三脚に固定し、2本とも同じ場所・同じ高さ・同じ向きで撮ります。三脚は滑走のあいだ動かさないでください。数メートル動かした差は合わせられません。
  • 滑っているあいだは、ズームもパンもしません。
  • 2本のあいだでズーム倍率が違っていても、アプリの「大きさ」で合わせられます。
  • カメラの傾きは2本で同じにします。アプリに回転の機能はありません。
  • 2本とも横長、または2本とも縦長にします。向きが違うとゲートや木が重なりません。
  • 手ぶれ補正の設定は2本で同じにします。途中で変えると、映る範囲がずれます。

何を映すか

  • スタートゲートなど、あとで「同じ瞬間」と分かる場面を両方に入れます。その少し前から録り始め、切りたい場所の先まで録ります。
  • ゲート、ネット、木など、位置を合わせる目印が画面に残るようにします。
  • 書き出せる長さは2分までです。それより長い滑走は、見たい区間の終わりで切ります。
  • 明るさが大きく違うと、ゴーストが見づらくなります。できるなら近い時間帯で撮ります。

音

  • カメラに入った音が、そのまま動画に入ります。マイクを切って撮ると、書き出しにも音はありません。
  • 風や声はあとから消せません。うるさい方は、アプリの音量で下げられます。
元の動画の渡し方。 AirDrop かケーブルで、撮影したファイルをそのまま渡します。LINE や Google フォトで送ると圧縮され、画角がずれて重ねられなくなります。完成した MP4 は、LINE やメールで渡して構いません。

用意するもの

  • 編集は iPad の Safari で行います。ページは ski-ghostline です。
  • iPad で書き出しが失敗する、または非常に遅いときは、同じページを Windows の Chrome または Edge で開きます。
  • 選手の端末にアプリは不要です。受け取った MP4 を再生するだけです。

操作手順

1. 動画を読み込む

  1. 「メイン（A）を選ぶ」で、下地にする滑走を選びます。
  2. 「ゴースト（B）を選ぶ」で、半透明にする滑走を選びます。

圧縮されたコピーではなく、撮影した元のファイルを選びます。

2. 開始と終了を印す

  1. バーを動かすか、「コマ送り」「コマ戻し」で、スタートゲートなど同じ瞬間まで進めます。1コマは30分の1秒です。
  2. メインとゴーストの両方で「開始」を押します。
  3. 雪景色だけになるなど、重ねなくてよい場所で、両方の「終了」を押します。

書き出しは、早く終了を迎えた方で止まります。開始と終了はタイマーではなく、重ねる範囲の印です。開始より前に終了があると書き出せません。

3. 位置と濃さを合わせる

  1. 開始のコマで、ゲートや木が重なるまでゴーストを指でドラッグします。
  2. 大きさが違うときは「大きさ」を動かすか、2本指で拡大します。25%から400%まで変えられます。
  3. 「ゴーストの濃さ」は10%から90%です。はじめは50%です。色は付きません。
  4. 「メインの音量」「ゴーストの音量」で、それぞれの動画に入っている音の大きさを決めます。0%にすると、その動画の音は入りません。
  5. 「プレビュー」で、開始から終了までを確認します。位置を最初からやり直すときは「位置をリセット」です。

4. 書き出す

  1. 「MP4 を書き出す」を押します。かかる時間は、書き出す動画の長さと同じくらいです。2分を超える範囲は書き出せません。
  2. 終わったら、下に出る動画で映像と音を確認します。
  3. 「MP4 を保存」で端末に残すか、「共有」から LINE やメールに渡します。ファイル名は ski-ghostline.mp4 です。

画面下に「メインとゴーストの音声あり」と出れば、両方の音が入っています。片方だけと出たときは、その動画に音が入っているか、音量が0%になっていないかを確認します。

うまくいかないとき

  • ページを更新したあとに古い動きが残るときは、Safari のタブを閉じて、アドレスを開き直します。
  • 「この動画は読めませんでした」と出たら、別の MP4 を選びます。LINE などで圧縮された動画は読めないことがあります。
  • iPad で書き出しが止まる、または終わらないときは、「中止」を押し、同じページを Windows の Chrome または Edge で開いて書き出します。
  • 長さが2分を超えると書き出せません。終了の印を前に動かします。
  • ゲートが重ならないときは、三脚の位置が2本で違っていないかを確認します。アプリで直せるのは位置と大きさだけです。
